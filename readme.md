## 📖 游戏介绍

南宋绍兴年间，碾玉匠崔宁与养娘璩秀秀两情相悦，却因一场大火被迫逃亡。面对告密、官府追捕、阴阳两隔的考验，你的每一次选择都将导向不同的命运。

游戏忠实还原原著情节，同时扩展了多条分支路线，总计 **21 种不同结局**，包括：

- 原著经典结局「**鬼妻索命**」
- 圆满结局「**携手轮回**」「**破镜重圆**」
- 悲剧结局「**长恨绵绵**」「**青灯古佛**」
- 复仇结局「**壮士断头**」「**冥府鸣冤**」
- 以及「**血溅三尺**」「**妻陷囹圄**」等十余种命运走向

## 🎯 玩法说明

- 玩家将扮演 **崔宁**，在剧情关键时刻做出选择。
- 每个选择都会影响后续剧情，部分支线包含 **2-3 个回合** 的持续推进。
- 游戏无存档功能，但可随时「重新开始」探索不同路线。
- 建议多周目游玩，收集全部结局。
